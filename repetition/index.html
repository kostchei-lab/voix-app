Répétition

Révise ton rôle : la page affiche le signal, écoute ta réplique, allume les mots dits et souffle à l'écran quand tu bloques.

Ton texte reste sur cet iPhone, dans la mémoire de la page ; il n'est envoyé nulle part. Pendant une séance, ta voix est reconnue par Apple, comme pour la dictée.

Ajouter un texte

Un PDF, un document Word (.docx) ou un fichier texte ; ou colle le texte copié ailleurs (site, PDF, Word). Chaque réplique commence par le nom du personnage : « NOM : texte », « NOM. — texte », ou le nom seul sur une ligne. Sans personnages (une poésie), tout le texte est à toi, paragraphe par paragraphe.

Un seul toucher : ensuite la page enchaîne seule. Lis le signal en silence, puis dis ta réplique. Après 3 s de blanc, elle souffle la première lettre, puis la moitié du mot, puis le mot.
